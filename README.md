## 日本語

ワークタイムとインターバルをくり返す、ブラウザで使えるインターバルタイマーです。
勉強・運動・絵の練習など、決まった時間で区切って何かに取り組みたいときに使えます。
インストールや登録は必要ありません。

**アプリを開く：** https://myaaazawa.github.io/intervaloop-timer/

### 主な機能

- ワークタイム・インターバル・繰り返し回数の設定（回数 0 で、止めるまでくり返す）
- 開始前のカウントダウン、合計時間の表示
- 残り時間が分かる丸いバー（ロックを解除すると、バーをなぞって時間を動かせる）
- 時間送り・巻き戻し（◀ N 秒 ▶）、今の区間の先頭へ戻る、スキップ
- 8種類の音（シンプル・ポーン・ピピピ・ホイッスル・チャイム・ベル・木琴・ブザー）と音量の調整
- 残り数秒で小さな音を鳴らす合図
- お気に入り（時間と回数の組み合わせを9件まで保存）
- 色の変更、背景（自動／ライト／ダーク）、日本語・英語の切り替え、全画面表示
- パソコン・スマートフォン・タブレットに対応

### 使い方

1. 「時間の設定」で、ワークタイム・インターバル・繰り返し回数を入力します。
2. 「開始」を押すと、カウントダウンのあとに計測が始まります。
3. 一時停止・再開・リセットは、丸いバーの下のボタンで行えます。

### キー操作（パソコン）

| キー | 動作 |
| --- | --- |
| Space | 開始／一時停止 |
| ← / → | 設定した時間だけ戻す／進める |
| Home | 今のワークタイム／インターバルの先頭へ |
| End / S | 今のワークタイム／インターバルをスキップ |
| Shift + R | リセット |
| M | 音のオン／オフ |
| 1〜9 | お気に入りを呼び出す（止まっているとき） |
| F | 全画面表示 |
| ? | キー操作の一覧を表示 |

キー操作は、このアプリのタブを選んでいるときだけ使えます。

### データとプライバシー

- 設定やお気に入りは、お使いのブラウザの中（ローカルストレージ）だけに保存されます。
- 入力した内容が、外部のサーバーに送信されることはありません。アクセス解析や広告も使っていません。

A browser-based interval timer that repeats work time and interval.
Use it for studying, workouts, drawing practice, or anything you want to do in timed blocks.
No installation or sign-up needed.

**Open the app:** https://myaaazawa.github.io/intervaloop-timer/

### Features

- Set work time, interval and repeat count (0 repeats until you stop)
- Countdown before start and total time display
- A ring that shows the remaining time (unlock it to drag the time along the ring)
- Back / forward by a set amount (◀ N sec ▶), restart the current part, and skip
- 8 sound types (Simple, Pong, Beep beep, Whistle, Chime, Bell, Xylophone, Buzzer) and volume control
- Soft beep in the last few seconds
- Favorites (save up to 9 time and repeat combinations)
- Custom colors, background (Auto / Light / Dark), Japanese and English, full screen
- Works on computers, smartphones and tablets

### How to use

1. In "Time", enter the work time, interval and repeat count.
2. Press "Start". The timer begins after the countdown.
3. Use the buttons below the ring to pause, resume or reset.

### Keyboard shortcuts (computer)

| Key | Action |
| --- | --- |
| Space | Start / pause |
| ← / → | Back / forward by the set time |
| Home | Restart the current work time / interval |
| End / S | Skip the current work time / interval |
| Shift + R | Reset |
| M | Sound on / off |
| 1–9 | Load a favorite (when stopped) |
| F | Full screen |
| ? | Show the shortcut list |

Shortcuts work only while this app's tab is selected.

### Data and privacy

- Your settings and favorites are saved only in your browser (local storage).
- Nothing you enter is sent to any server. The app uses no analytics and no ads.
- Settings are not shared with other browsers or devices.
- Clearing your browser data also deletes your saved settings.
